# Претензии · pretenzii.mebel-arigato.ru

Приложение для фиксации и ведения рекламаций по регламенту «три срока и прозрачный статус».

## Что умеет

- **Приём с телефона**: скан претензии и фото дефектов с камеры. Плюс ФИО, телефон, email, адрес, номер и дата договора, тип договора, стоимость и требование клиента. Кто принял и когда — фиксируется автоматически.
- **Рассылка**: копия претензии с вложениями уходит начальнику производства (владелец претензии), РОПу и сборщикам. Клиенту — подтверждение с номером и ссылкой на статус.
- **Три срока**:
  - рассмотрение — 2 дня;
  - план исполнения — в днях;
  - юридический срок — 30 дней на ремонт или переделку, 10 дней на денежные требования.
  Если конец срока выпадает на выходной или праздник, он переносится на рабочий день. Первоначальный срок хранится всегда, изменить его нельзя.
- **Перенос срока**. Если план не укладывается в срок, система подсвечивает это и предлагает отправить клиенту письмо с новой датой. Клиент нажимает «Согласен» или «Не согласен». Срок меняется только после согласия клиента. При отказе — эскалация директору.
- **Ежедневные напоминания** в 9:00. В Telegram — с кнопками «Сделано», «Проблема», «Нужна помощь» и комментарием; без Telegram — на email. Если к 18:00 нет отметки, это фиксируется как игнор. 2 дня игнора — сообщение начальнику производства, 3 дня без движения — директору.
- **Предупреждения о сроках**:
  - 50% срока — начальнику производства;
  - 75% — начальнику производства и РОПу;
  - 90% — директору;
  - просрочка — каждый день, с расчётом неустойки: 3% в день для подряда, 1% для купли-продажи.
- **Закрытие**. Закрыть претензию нельзя, пока нет всего этого:
  - акта или фото «после»;
  - подтверждения клиента (по ссылке или подписанный акт);
  - разбора причины из 4 полей;
  - согласованных компенсаций.
- **Стоимость рекламации**: работа, материалы, фурнитура, выезды, компенсации. Каждая статья — за счёт компании, бригады, технолога, дизайнера или поставщика. Компенсацию до 10 000 ₽ согласует РОП, свыше — директор.
- **Отзыв клиента**: через 48 часов после подтверждения клиенту уходит опрос. Оценка 1–2 или «проблема не решена» автоматически переоткрывает претензию.
- **Повторяющиеся причины**: 3 претензии с одной причиной за 90 дней — уведомление директору и начальнику производства.
- **Журнал**: каждое действие записывается — кто, когда, было, стало, комментарий. Записи журнала и сами претензии удалить невозможно, это запрещено на уровне базы данных.
- **Показатели и выгрузка**:
  - доля исполненных в срок, просрочки, медиана исполнения;
  - оценки клиентов, стоимость и удержания;
  - рейтинг причин и сотрудников;
  - выгрузка в CSV для Excel.

## Сотрудники без почты

- Вход по номеру телефона и паролю. Email у сотрудника не обязателен.
- Все уведомления сотрудникам идут в Telegram: копии претензий со сканами и фото, ежедневные отметки кнопками, эскалации. В «Сотрудниках» у каждого есть одноразовая ссылка на бота и кнопка «Отправить в WhatsApp».
- Клиенту без email: в карточке кнопки WhatsApp / Telegram / SMS. Открывается сообщение со ссылкой на статус, отправка фиксируется в журнале.
- Подключение бота: `bash <(curl -fsSL https://raw.githubusercontent.com/dilessons-ux/pretenzii/main/deploy/telegram.sh)`.
- Обновление: `curl -fsSL https://raw.githubusercontent.com/dilessons-ux/pretenzii/main/deploy/update.sh | bash`.

## Роли

| Роль | Права |
| --- | --- |
| Директор | Всё + сотрудники, компенсации свыше 10 000 ₽ |
| Начальник производства | Владелец претензий: решение, разбор причины, закрытие |
| РОП | Решение, перенос срока, компенсации до 10 000 ₽ |
| Снабжение | Перенос срока (дата поставки), затраты |
| Сборщик, технолог, дизайнер, сотрудник | Приём претензий, отметки, фото |

## Установка на сервер (VPS в РФ, Ubuntu 22/24)

Нужно: VPS 1 ядро / 1–2 ГБ (Timeweb, Selectel, Yandex Cloud), Docker, nginx, доступ к DNS домена mebel-arigato.ru.

1. **DNS**: в панели домена добавить A-запись `pretenzii` → IP сервера.
2. **Код на сервер**:
   ```bash
   sudo mkdir -p /opt/pretenzii && cd /opt/pretenzii
   # распаковать архив сюда
   cp .env.example .env && nano .env    # заполнить SECRET_KEY, ADMIN_*, SMTP_*, TELEGRAM_*
   docker compose up -d --build
   curl localhost:8000/health           # {"ok":true}
   ```
3. **nginx и HTTPS**:
   ```bash
   sudo cp deploy/nginx-pretenzii.conf /etc/nginx/sites-available/pretenzii
   sudo ln -s /etc/nginx/sites-available/pretenzii /etc/nginx/sites-enabled/
   sudo nginx -t && sudo systemctl reload nginx
   sudo certbot --nginx -d pretenzii.mebel-arigato.ru
   ```
4. **Резервные копии**:
   ```bash
   sudo apt install sqlite3
   crontab -e   # добавить строку: 30 3 * * * /opt/pretenzii/deploy/backup.sh
   ```
5. **Первый вход**: https://pretenzii.mebel-arigato.ru под ADMIN_EMAIL / ADMIN_PASSWORD. Затем:
   - «Сотрудники» → добавить начальника производства, РОПа, сборщиков, технолога, дизайнера, снабженца;
   - каждый сотрудник в «Профиле» нажимает «Привязать Telegram».

### Почта
Для Яндекс 360: создать ящик `pretenzii@mebel-arigato.ru`, включить пароль приложения, вписать его в `SMTP_PASSWORD`.
Без SMTP письма не уходят, а записываются в `data/outbox.log` — удобно для проверки.

### Telegram-бот
@BotFather → `/newbot` → токен в `TELEGRAM_BOT_TOKEN`, имя бота в `TELEGRAM_BOT_NAME`, затем `docker compose up -d`.

### Персональные данные (152-ФЗ)
Сервер должен быть в РФ. Ссылку на политику обработки ПДн добавьте в договор и на сайт. Доступ к приложению — только по логину сотрудника. Страница клиента открывается только по уникальной секретной ссылке.

## Обновление
```bash
cd /opt/pretenzii && docker compose up -d --build
```
Данные в папке `data/` при обновлении сохраняются.
